#  Contributing to FrAIm

FrAIm is open source, so you can checkout the main branch on GitHub and implement any of your features yourself.

A good point to start looking for open topics would be [this file](../../bugs.txt).

Alternatively, one of the most important things you can do is use FrAIm and provide feedback!
If you find any bugs, please let us know and start an issue on GitHub.
